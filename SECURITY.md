# SECURITY.md

## Security Policy

### Reporting a Vulnerability

If you discover a security vulnerability, please report it by opening an issue or contacting the project maintainers directly. We will respond as quickly as possible to address the issue.

- Do not post sensitive information publicly.
- Use responsible disclosure practices.

## Best Practices
- No secrets or credentials in code or Docker images
- Use environment variables for sensitive config
- Input validation and error handling throughout
- Regular dependency updates
